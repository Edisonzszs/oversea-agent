# 合规自查 · 行动建议规则清单

> 来源:`src/app/compliance/logic/scoring.ts`(头部注明"忠实移植自合规 HTML 第五版 genReport()")。
> 本清单把 `computeItems()`(行 154-378)与 `Z_ACT` 查表(行 71-78)里**所有行动建议触发点(~43 条)**逐条列出,供通览与改写。
> 生成日期:2026-08-11。

## 档位与排序

- **D** = 红线 / 前置门槛(不得申报)
- **C** = 须先解决再申报
- **B** = 补充材料即可
- A = 达标,**不出行动**
- 报告最终按 **D → C → B** 硬排序(`buildReport()` 行 444)。
- **机构匹配**:`svcOrgs()`(行 424-431)对 D/C 档行动按关键词挂"可寻求协助机构"——法律/尽调/律师→律师事务所;审计/验资→会计师事务所;银行资金→银行;估值/可比案例→评估机构。**B 档不挂机构**。

## 通览要点

### D 档红线(共 5 条,全报告最高优先级)

任一命中 → 整报告档位锁 D,**不建议申报**:

1. z1 / z2 / z3 / z4 的 **d 档**(主体资格前置门槛:架构、主业、资金、违规记录)
2. g2 = "d" —— 关联交易拟不披露
3. 三套负面清单触及**禁止类**(lsC)
4. 出口管制涉**禁止出口**内容(s1c 其余)

> 注:z5 / z6 的 d 档虽也标 D,但不属于"前置门槛"——z5/z6 是审慎判断项,命中 d 会让档位降到 D 但表述为"先行处理再申报"而非"不得申报"。
